# Changelog

Each entry is one version of this template. Breaking changes are listed first.

## 1.20.1 (2026-11-16)

- First release: Qdrant v1.20.1 (`qdrant/qdrant:v1.20.1@sha256:d18c8e5061be3eaea2f53fbee1f0bf0382dc59cbb9b7112e41ffcc937ec14220`).
- Storage and snapshots on one Railway volume at `/qdrant/data`.
- API key required (generated by the template); the container refuses to start without one.
- HTTP API and Web UI on the public domain (`$PORT`, default 6333); gRPC on port 6334 over Railway's private network.
